# 激辛注意！わんこそばチャレンジ (Wankosoba Challenge)

Javaの基本文法と標準ライブラリを活用して作成した、コンソール上で遊べるテキストベースのゲームです。

## ゲーム概要
キーボードの Enter キーを押して、ひたすら「わんこそば」を食べ進めるゲームです。
ランダムな確率で発生する「激辛わんこそば」のダメージに耐えながら、最高記録を目指します。

## 主な機能・特徴
- **`while` ループによるゲームシステム**: プレイヤーが脱落するまで継続する動的なゲームループ。
- **`Scanner` による対話型入力**: Enterキーでテンポよくゲームを進行。
- **確率分岐とスリル要素**:
    - `Math.random()` による乱数発生（50面サイコロ）。
    - 1が出たら「満腹」で即ゲームオーバー。
    - 2〜8が出たら「激辛わんこそば」で30ダメージ！
    - それ以外は通常のわんこそば（HPが1回復）。
- **HP・ダメージ管理**:
    - 初期HPは100。激辛で減少し、通常そばで回復（上限100）。
    - HPが0になると舌が痛くなってリタイア（ゲームオーバー）。

## 使用技術
- Java 21+
- Java Standard Library (`java.util.Scanner`)

##  実行方法
`main` メソッドを含むファイルを実行し、コンソールの指示に従って Enter キーを押してください。
